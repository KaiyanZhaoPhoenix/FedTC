# 下一版设计：相对收益证据与自适应

**状态：研究提案，尚未实现、训练或获得新保证。** 本次仓库整理不改变已完成的控制器和实验。

1. 先从相同模型与上传更新的快照比较一小组 `(lambda,tau)`，用私有验证集确认是否存在比保守动作更好的选择、不同阶段是否偏好不同参数。预先定义少数群体，不能按最终结果选出“少数”。
2. 研究同一评估客户端、同一留出数据上的配对差值 `d_i = loss_i(w_cons) - loss_i(w_candidate)`，为候选相对保守的诚实平均改善构建抗造假的区间。先用 H=1 的双聚合模型验证；这会增加模型下发和验证成本。
3. 先用全部客户端评估隔离抽样误差。全量评估消除客户端抽样误差，不消除恶意身份不确定性。配对不会自动缩窄最坏情形界，方差自适应/有限总体界需要在污染模型下重新推导。
4. 在诚实反馈诊断中比较固定参数、随机调参、gamma=0 和 SAC，保持奖励及尺度相同；检查奖励与熵的相对量级，增加真实环境交互而不只重复更新旧经验。
5. 配对候选的评价可以用于辅助监督；未执行动作不能与实际执行路径的下一状态拼成 SAC transition。保持 replay 中动作和实际环境转移一致。
6. 重新验证门控：有收益时允许调整，造假时限制退化。动作变化率或放行率本身不是优化成功指标，也不能通过调大容忍量来替代证据。

只有这些机制在单种子诊断中获得实际收益证据后，再扩展种子、数据集和正文套件。若依旧没有相对固定策略的收益，应收窄或修改方法主张。
