# 当前限制与可以成立的结论

1. 最新四组对照只有 MNIST、seed=1、同值模型攻击；反馈条件不同不构成独立随机种子。
2. 原 FedTC 与 SAC 加门控在每种条件下均 134/134 次回退，实际使用固定保守动作。不能把其准确率归因于有效动态控制。
3. 无门控 SAC 产生不同动作并完成学习，但本次未优于保守执行路径；150 条环境交互不构成收敛证明。
4. 全部主实验中恶意更新权重均为零，当前明显离群攻击已被前向规则过滤。尚不能据此验证对边界内攻击或动态攻击的自适应收益。
5. 全局诚实客户端样本加权准确率、客户端宏平均、事后底部 20% 客户端准确率是不同指标。后者不是预先定义的稀有类别/少数群体保护。
6. 反馈区间的总体均值覆盖不自动传递到神经 Critic，也不构成门控或长期策略的安全定理。
7. 原门控比较候选下端点和保守上端点。宽区间会使相近候选也无法通过；经验池只有保守动作时，其他动作缺乏执行证据。
8. 原 `paper` TD 与当前 PopArt 原始 Q 保持约定存在已记录的不一致；`consistent` 是独立诊断选项，不静默替换历史算法。
9. SAC 改变了奖励目标和归一化，不是仅替换优化器。门控的纯对照是两个 SAC 版本之间。
10. 现有 FedAA 对照仍使用原生服务器干净奖励数据；不能把双方都称为无服务器数据方法。早期 12 客户端结果也不能推广成完整基线结论。
11. 论文中的 CIFAR、ALIE、Min-Max、动态切换和少数类别表格是计划。历史配图不作为已验证实验展示。
12. 原数据划分合并了官方 MNIST train/test；当前测试集不是官方独立 test split。小客户端 `drop_last` 行为原样保留。

可以报告的是：代码集成、共享比较协议、前向规则在当前攻击下的行为、反馈污染和门控阻断现象，以及单次运行的测量值。尚不能报告“FedTC 完整创新已成功验证”“SAC 必然更好”或“少数群体/长期安全已获保证”。
