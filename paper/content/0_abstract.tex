\begin{abstract}
Federated learning (FL) under non-IID data faces a persistent \emph{robustness--heterogeneity dilemma}: tightening static filters blocks poisoning yet starves honest minority clients with rare data, whereas relaxing them invites boundary-hugging attacks. Adaptive control offers a way out, but zero-trust deployments deny the server both clean proxy data and trustworthy client feedback.

We propose \textbf{FedTC}, a server-data-free framework closing the loop between a \emph{Forward Calibration Layer} and a \emph{Backward Confidence-Interval Controller}. Every round, the forward layer anchors updates at the geometric median, cross-checks cohort-scaled deviations against rank-normalized utility claims, and applies a smooth rectifier with an exact cutoff radius---preventing weight collapse while capping fake utility influence. Every $H$ rounds, the backward controller queries a decoupled evaluator cohort for bounded local loss changes and builds a confidence interval $[L_n, U_n]$ via worst-case tail trimming. Unlike median-residual filtering, $[L_n, U_n]$ preserves honest minority alerts in $L_n$, guiding PopArt-normalized dual critics and an execution-level fallback gate against a conservative baseline. We establish forward boundedness, separation, and finite-sample containment guarantees, and outline an evaluation suite across static and non-stationary attacks.
\end{abstract}
